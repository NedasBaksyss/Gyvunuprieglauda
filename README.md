# Paleidimas

Reikia Node.js 24 arba naujesnės versijos. Projekto aplanke vykdykite:

```bash
npm install
npm run db:seed
npm run user:create
npm run dev
```

Komanda `user:create` paprašys įvesti paskyros duomenis. Administratoriui pasirinkite rolę `admin`.

Atidarykite http://localhost:5173.

Kitą kartą paleidžiant užtenka `npm run dev`.
